### 一、 核心玩法与机制拓展

#### 1. 丰富花瓣种类、与套装联动
*   **现状**：目前仅有 `melee` (近战)、`explosive` (爆炸)、`missile` (远程发射)、`speed` (移速)、`guardian` (守护) 5 种。
*   **解决方案**：
    *   **毒素花瓣**：击中敌人造成叠层 DOT 伤害。
    *   **冰冻花瓣**：降低敌人移动速度，甚至冻结敌人。
    *   **吸血花瓣**：造成伤害时按比例恢复玩家血量。
    *   **磁铁花瓣**：扩大掉落物的自动拾取半径。

#### 2. 敌人多样性与 Boss 战机制
*   **现状**：只有 `basic`、`dasher` (冲锋)、`bomber` (自爆) 3 种敌人，随深度和等级增加数值。
*   **解决方案**：
    *   **远程敌人**：会在一定距离外向玩家发射子弹。
    *   **召唤型敌人**：会不断孵化小怪。

#### 3. 角色加点/天赋系统
*   **现状**：升级仅自动增加 HP 和 XP 上限。
*   **解决方案**：
    *   每次升级提供 **三选一随机 Buff**（如：+10% 旋转速度、+15% 拾取范围、-10% 花瓣冷却时间、+5% 暴击率）。

### 二、 视听体验强化

#### 1. 渲染细节与图形美化
*   **现状**：花瓣和玩家都是基础的 Canvas `ellipse` 或 `arc` 圆形。
*   **解决方案**：
    *   **花瓣形状**：使用贝塞尔曲线绘制真实的“水滴形/花瓣形” Polygon，而不是纯椭圆。
    *   **发光与拖尾效果**：为高品质花瓣（Legendary / Mythic）增加 `ctx.shadowBlur` 粒子拖尾，或者在移动时留下渐隐轨迹。
    *   **受击反馈**：敌人被击中时除了闪白，可以增加轻微的“向后击退 (Knockback)”动画。

### 三、 UI / UX 与品质提升

#### 1. 自动一键合成
*   **现状**：合成需要手动点击 `5 普通 -> 1 不凡` 按钮，后期低阶花瓣堆积时点击极其繁琐。
*   **解决方案**：
    *   增加一个 **“一键合成所有”** 按钮。

#### 2. 更丰富的 Tooltip（悬浮提示）
*   **现状**：背包里仅显示品质名称。
*   **解决方案**：
    *   鼠标悬浮在花瓣上时，显示详细卡牌提示框：
        *   基础伤害 / 冷却时间 / 特殊属性（如：“移速 +15%”、“爆炸伤害 250%”）。

#### 3. 完成图鉴系统 (Codex)
*   **现状**：HTML 中有被注释掉的 `<!-- Esc 键：查看花瓣 / 怪物图鉴（未完成） -->`。
*   **解决方案**：
    *   实现图鉴面板，记录玩家解锁过的花瓣品质/类型以及击杀过的怪物种类，增强收集乐趣。
